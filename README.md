# Online Examination System

A complete web-based Online Examination System that allows educational institutions to create, manage, and conduct online exams securely.

## Features

- **Multi-role System**
  - Admin
  - Teacher
  - Exam Committee
  - Student

- **Admin Panel**
  - Manage users and roles
  - Manage courses
  - System settings
  - View enrollments

- **Teacher Panel**
  - Create and manage questions
  - Question bank
  - View student results

- **Exam Committee Panel**
  - Schedule exams
  - Approve questions
  - Generate reports

- **Student Panel**
  - Register for exams
  - Take timed online exams
  - View results
  - Download certificates

- **Other Features**
  - Automatic grading
  - Certificate generation
  - Email notifications
  - Database backup system
  - Secure authentication

## Technologies Used

- PHP
- MySQL
- HTML, CSS, JavaScript
- Bootstrap (for UI)
- XAMPP (for local development)
